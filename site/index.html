features

Everything here ships in the desktop app — no plugins, no separate window.

Project workspaces

Terminals grouped by project with their own directories and state. Split panes, a Windows Terminal-style tab bar, drag-and-drop reordering.

ACP agent chat

Claude Agent, Codex, Gemini CLI, Cursor, OpenCode — in any pane, with model picker, slash commands, @ file mentions and permission prompts.

Git & worktrees

Stage hunks, inline or side-by-side diffs, history graph, branches, stash. Create a worktree from any base and switch between them.

SSH & SFTP

Native SSH on russh — no system ssh needed. Saved hosts, host-key verification by fingerprint, an SFTP browser and in-place editor.

Remote & mobile

Turn on remote access for a cloudflared tunnel, scan the QR code, and drive your live agent chats from a phone. Installable as a PWA.

Editor, browser, tools

Code and markdown editors with Mermaid, an embedded browser with a page-annotation toolbar, ripgrep project search and live file watching.
