---
title: Install itzTerm
description: Install the itzTerm desktop app on macOS, Windows, or Linux.
---

The desktop app is called **itzTerm**. Every release has builds for macOS, Windows, and Linux on the [GitHub releases page](https://github.com/latiefahmad/itzTerm/releases/latest).

If you want to run itzTerm on a server and open it in a browser or on your phone, install `itzterm-server` instead. See [Browser and phone](/docs/remote).

## macOS

You can install itzTerm with Homebrew, with the install script, or from a disk image. All three give you the same app.

### Homebrew

```bash
brew tap latiefahmad/itzTerm
brew install --cask itzterm
```

### Install script

```bash
curl -fsSL https://raw.githubusercontent.com/latiefahmad/itzTerm/v0.4.21/scripts/install.sh | bash
```

The link points to the script from a fixed release, so it can't change under you. The script still installs the newest itzTerm release.

The script does these things:

1. It finds the latest release and the disk image for your Mac (Apple silicon or Intel).
2. It asks `Install itzTerm <version> (...) to /Applications? [y/N]`. Type `y` and press Enter.
3. It downloads the disk image and checks it against the release checksums. If the check fails, it installs nothing.
4. It copies **itzTerm.app** to `/Applications`.

To skip the question, run the script with `ITZTERM_INSTALL_YES=1`. To install somewhere other than `/Applications`, set `ITZTERM_INSTALL_APPLICATIONS_DIR`.

### Disk image

1. Open the [latest release](https://github.com/latiefahmad/itzTerm/releases/latest).
2. Download the `.dmg` for your Mac. The file ending in `_aarch64.dmg` is for Apple silicon. The file ending in `_x64.dmg` is for Intel.
3. Open the `.dmg` and drag **itzTerm** into **Applications**.

## Windows

1. Open the [latest release](https://github.com/latiefahmad/itzTerm/releases/latest).
2. Download the file ending in `_x64-setup.exe` or the file ending in `_x64_en-US.msi`. Both install the same app. Builds are for 64-bit x86 Windows.
3. Run the installer.

The install script does not work on Windows.

## Linux

Linux builds are for 64-bit x86 (`x86_64`) only.

### Install script (AppImage)

```bash
curl -fsSL https://raw.githubusercontent.com/latiefahmad/itzTerm/v0.4.21/scripts/install.sh | bash
```

The script downloads the latest AppImage and checks it against the release checksums. Then it does these things:

- It saves the app as `~/.local/bin/itzterm-manager`.
- It adds a **itzTerm** entry to your application menu.
- It warns you if `~/.local/bin` is not on your `PATH`. Add that folder to your `PATH` to start itzTerm from a shell with `itzterm-manager`.

Before it installs, the script asks you to confirm. To skip the question, run it with `ITZTERM_INSTALL_YES=1`. To use a different folder, set `ITZTERM_INSTALL_BIN_DIR`.

### Debian, Ubuntu, Fedora, and other packages

The [latest release](https://github.com/latiefahmad/itzTerm/releases/latest) also has these files:

- A `.deb` package (`itzTerm.Manager_<version>_amd64.deb`) for Debian, Ubuntu, and similar systems.
- An `.rpm` package (`itzTerm.Manager-<version>-1.x86_64.rpm`) for Fedora and similar systems.
- The `.AppImage` file, if you want to manage it yourself.

Install the package with your system's package manager. For example, on Ubuntu:

```bash
sudo apt install ./itzTerm.Manager_<version>_amd64.deb
```

### Arch Linux (AUR)

itzTerm is in the AUR as `itzterm-manager`. Install it with your AUR helper. For example:

```bash
yay -S itzterm-manager
```

## Updates

The desktop app checks for new versions and can install them for you. You can pick the **Stable**, **Insider**, or **Nightly** channel. See [Settings](/docs/settings) for details.
